# Literature reviews

Web literature reviews for the MAXI J1820+070 Lorentzian/QPO project,
compiled by search agents. Citations marked **[UNVERIFIED]** must be
checked on ADS before use.

| File | Scope |
|---|---|
| `review_round1.md` | Core MAXI J1820+070 timing results (QPO track, state timeline), Lorentzian methodology, statistics (F-test, Whittle), NICER reduction recipe, tools, physical models, ranked recommendations |
| `review_round2.md` | Extended directions: other black-hole transients, IXPE/multiwavelength, GP/ML/time-domain methods, spectral-timing from event data, hierarchical statistics, power colours, NICER 2022-2026 changes, theory to test, reproducibility, research-direction map |
| `review_round3.md` | Gap-fill and novelty check: prior per-ObsID catalogues, recent papers, other missions, software, bright-source NICER systematics, NS/AGN/ULX comparisons |

**Read round 3 §0 first.** It supersedes the round-2 novelty verdict:
Stiele & Kong (2020, ApJ 889, 142; VizieR J/ApJ/889/142) already publish a
per-epoch NICER multi-Lorentzian table for the 2018 rise. Round 3 §0.3 lists
corrections (C1-C10) to rounds 1 and 2.
